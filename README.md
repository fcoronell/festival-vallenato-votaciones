# Sistema Web de Votaciones — Festival de la Leyenda Vallenata 2027

Proyecto académico del curso **Desarrollo Web (grupo 61)** de la Fundación Universitaria del Área Andina.
Docente: Deivys Morales Uribe.

Es un sistema web para organizar votaciones por **edición** anual del Festival. Una edición tiene categorías, cada categoría tiene votaciones y cada votación tiene opciones participantes. El sistema se puede reutilizar año tras año sin cambiar el código.

> 🚧 En construcción: **Entrega 2 — Desarrollo inicial**. Las instrucciones completas de instalación y ejecución se agregarán al terminar el proyecto base.

## Tecnologías

- Python 3.13
- Django 5.2 LTS (patrón MVT)
- MySQL 8.4 LTS
- HTML5, CSS3, Bootstrap 5 y JavaScript
